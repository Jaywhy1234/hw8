如何將此專案部署至 GitHub Pages

只要簡單幾個步驟，就能免費將網頁版 AI 辨識應用程式發布到網路上供所有人遊玩！

1 準備程式碼檔案

將上方產生的完整程式碼儲存為單一 HTML 檔案，命名為 index.html。

2 建立 GitHub 倉庫 (Repository)

  • 登入 GitHub 並點擊右上角的 + 選擇 New repository。
  • 輸入 Repository 名稱（例如 ai-classifier-game）。
  • 選擇 Public（公開），並勾選 Add a README file，然後點擊 Create repository。

3 上傳 index.html 檔案

  • 進入您的新專案頁面，點擊 Add file -> Upload files。
  • 將您的 index.html 拖曳上傳至頁面中。
  • 點擊下方綠色的 Commit changes 按鈕儲存。

4 啟用 GitHub Pages 服務

  • 點擊專案上方的 Settings（設定）標籤。
  • 在左側選單中找到 Pages。
  • 在 Build and deployment 的 Branch 區段，將來源分支設定為 main（或 master），資料夾維持 / (root)，點擊 Save。
  • 等待約 1 分鐘後重新整理頁面，上方就會顯示您的公開網址（例如 https://您的帳號.github.io/專案名稱/）。點擊即可在手機或電腦上直接使用相機遊玩！
